# DUTA CNARYY

Welcome to the DUTA CNARYY project! This is a modern and responsive website for a premium canary bird store, designed using HTML, CSS, JavaScript, React, and Next.js. 

## Features

- Elegant design with a color scheme of yellow, black, and white.
- Responsive layout that adapts to various screen sizes.
- Home page featuring a hero section, product listings, and customer testimonials.
- Components for easy maintenance and scalability.

## Installation

To get started with the DUTA CNARYY project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd duta-cnaryy
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Run the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to see the website in action.

## Usage

- The homepage showcases the hero section, product cards, and testimonials.
- Each product card displays the image, price, age, and type of canary.
- The footer contains contact information and links to social media.
